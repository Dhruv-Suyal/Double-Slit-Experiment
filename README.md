# 🌊 Interactive Double-Slit Experiment

An interactive 3D visualization of the **Double-Slit Experiment** that demonstrates wave interference and the effect of which-path observation.

The project allows you to add or remove a which-path observer and visually compare the resulting photon distribution.

## 📖 About the Project

The Double-Slit Experiment is one of the most important experiments in modern physics.

It demonstrates that light and other quantum objects can exhibit **wave-like behavior**, particularly through interference.

In this project, you can interact with a simplified visualization of the experiment:

- Send photons toward two slits.
- Observe the interference pattern when no which-path information is available.
- Add a which-path observer.
- Send photons again and compare the resulting distribution.
- Rotate and zoom the 3D scene.

The goal is to make the basic ideas behind quantum interference easier to understand through visualization rather than only equations.
